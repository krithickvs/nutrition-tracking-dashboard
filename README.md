# 🥗 Nutrition and Weight Tracking Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard designed to monitor nutrition intake, body weight progression, calorie consumption, and training consistency over time.

The dashboard helps track fitness goals across different nutrition phases such as:

- 💪 Bulk
- ⚖️ Body Recomposition
- 🔥 Cut

It provides meaningful insights into macronutrient distribution, weight trends, calorie intake, and workout consistency.

---

# 📊 Dashboard Features

## 🥦 Nutrition Tracking
- Average Protein Intake
- Average Carbohydrate Intake
- Average Fat Intake
- Macronutrient Distribution Visualization

---

## ⚖️ Weight Monitoring
- Weight Trend Analysis
- Weight Change Tracking
- Average Weekly Weight
- Phase-wise Weight Comparison

---

## 🔥 Fitness & Training Insights
- Training Completion Percentage
- Nutrition Phase Tracking
- Mesocycle & Weekly Filtering
- Performance Monitoring

---
